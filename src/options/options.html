GitHub accounts

A token is needed to read private pull requests and to post review comments from the overlay. Without one the extension still renders diffs of anything your browser session can already see, in read-only mode.

GitHub Enterprise

Add the hostname of a self-hosted GitHub. Each host needs its own OAuth App registered on that instance with device flow enabled; without one, connect with a personal access token instead.

How the token is stored

The token is encrypted with AES-GCM before it is written to disk, using a key that is generated non-extractable — its bytes cannot be read back out, so copying the browser profile or inspecting extension storage does not yield a usable token. It is held in memory only inside the extension's background worker, and is never passed to a page or written to a log.

It does not protect against code running with this extension's own privileges: such code can ask for a decryption just as the extension does. Treat it as encryption at rest, and nothing stronger.
